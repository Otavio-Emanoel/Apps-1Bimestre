# Apps-1Bimestre

Este repositório reúne 7 aplicativos em C# com Windows Forms, desenvolvidos no curso de Desenvolvimento de Sistemas. Cada aplicativo corresponde a uma proposta ou desafio diferente, abordando lógica de programação, interface gráfica, validação de dados e criatividade.

---

## 📦 Descrição dos Aplicativos

**App 1/7 - Calculadora de Peso Ideal**  
Recebe dados do usuário e calcula qual seria seu peso ideal, conforme critérios definidos no sistema.

**App 2/7 - Cálculo de Média Anual**  
Permite digitar o nome do aluno, os nomes de dois componentes e as menções dos quatro bimestres de cada componente. Calcula e exibe a média anual de cada disciplina.

**App 3/7 - Controle de Funcionários e EPI**  
Recebe o nome do funcionário, quantidade de faltas, uso de EPI (sim/não) e salário. Exibe os dados e aplica bônus de R$500,00 ao salário como bonificação para quem utiliza EPI e falta pouco.

**App 4/7 - Habilitação de Motorista**  
Recebe nome, idade e tipo de carteira desejada. Informa se a pessoa pode tirar habilitação e permite escolher a categoria (A, B, C, D ou E).

**App 5/7 - Classificador de Triângulo**  
Recebe os três lados de um triângulo e informa se eles realmente formam um triângulo. Caso positivo, classifica como escaleno, equilátero ou isósceles.

**App 6/7 - Tema Livre**  
Aplicativo de tema livre criado pelo aluno, contendo ao menos 3 campos e 3 botões. O tema não repete os anteriores.

**App 7/7 - Tema Livre**  
Outro aplicativo de tema livre, também com no mínimo 3 campos e 3 botões, e tema diferente dos anteriores.
